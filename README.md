# ☕ CoffeeDB

A modern web application for coffee enthusiasts to discover, review, and explore specialty coffees and coffee businesses.

## 🌐 Live Demo

**[CoffeeDB](http://srv17.mikr.us:40330/)**

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Coffee Database** | Browse detailed coffee profiles with flavor notes, origin information, processing methods, and roast profiles from around the world |
| **Coffee Shop Directory** | Discover local and international coffee shops with detailed profiles, location data, and visitor reviews |
| **Roastery Directory** | Explore coffee roasters with interactive maps, contact information, and their specialty offerings |
| **Integrated Maps** | Find coffee establishments near you with detailed ratings, amenities, and precise location information |
| **Review System** | Share opinions about your favorite coffees, roasteries, and shops with rating system and personalized feedback |
| **Search & Filtering** | Find exactly what you're looking for with intuitive filters for location, rating, flavors, and more |
| **Responsive Design** | Enjoy a seamless experience across desktop, tablet, and mobile devices with our adaptive interface |
| **Dynamic Content Loading** | Real-time updates of coffee, roastery and shop information without page reloads |
| **User Authentication** | Secure login and registration system allowing personalized experiences |

---

## 🔧 Tech Stack

### Frontend
- HTML5, CSS3 with responsive design principles
- JavaScript for dynamic content
- Interactive maps with Leaflet.js integration
- Modern UI with CSS Grid and Flexbox layouts

### Backend
- **Primary**: Flask  web framework
- **Microservices**: Go for high-performance API endpoints
- RESTful architecture with JSON data exchange
- JWT-based authentication flow

## 🚀 Use Cases

- 🔍 Discover new coffees based on flavor preferences and origin
